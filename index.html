Multi-Node Telemetry & Network Probe Architecture

How VORA Sentinel communicates with secondary laptops, mobile smartphones, virtual machines, and IoT perimeter sensors across public internet networks.

1. Mobile Phone Probe Node

Any candidate, auditor, or tutor can access /mobile-node.html on iOS or Android. The browser client automatically gathers client IP, battery telemetry, and transmits encrypted JSON heartbeats to /api/sentinel/telemetry.

2. Python Linux VM / Raspberry Pi Agent

The standalone Python agent (agent/sentinel_agent.py) runs on Linux, macOS, or Windows. It uses standard library sockets and HTTP to inspect local network traffic and forward suspicious domain queries directly to the cloud backend.

3. Automated Rate Limiter & IP Defense

External devices exceeding 5 failed authentications or sending rapid threat vectors trigger the automated rate-limiting shield, logging an incident into the SQLite / Cloud database and notifying the SOC dashboard.
