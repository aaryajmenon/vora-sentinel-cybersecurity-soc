1. Executive Summary & Abstract

Online recruitment scams and corporate identity impersonation represent one of the fastest-growing attack vectors in contemporary social engineering. According to threat intelligence reports from the Federal Bureau of Investigation (FBI IC3) and INTERPOL, deceptive hiring syndicates inflict over $2.7 Billion in annual global losses, harvesting sensitive candidate PII (Personally Identifiable Information) and executing advance-fee extortion scams using typosquatted domains and forged enterprise appointment letters.

VORA Sentinel is an autonomous, complete-stack cybersecurity platform engineered to intercept, analyze, and neutralize cyber recruitment fraud in real time. It establishes a multi-layered verification barrier that cross-references candidate domains, communication vectors, and job appointment letters against cryptographically authenticated corporate benchmarks. The system combines:

  • Complete Multi-Tier Stack: Responsive Web Portal, RESTful Backend (Python Flask + Netlify Cloud Serverless API), and Persistent Relational Database (SQLite / Cloud MongoDB Atlas).
  • Mathematical Detection Engines: Damerau-Levenshtein distance calculation, Shannon Entropy profiling, RFC 3490 Punycode homograph decoding, and heuristic advance-fee extortion extraction.
  • Mandatory External Device Integration: Bidirectional telemetry integration connecting the live cloud platform to external mobile smartphones and secondary laptops/VMs.
  • Real-Time Security Operations Center (SOC) Dashboard: Live threat streams, active node telemetry, incident queue mitigation, and attack simulation laboratory.

5. Cybersecurity Detection Engines & Mathematical Models

5.1 Damerau-Levenshtein Edit Distance Metric

To detect lookalike domains (e.g., g00gle.com vs google.com), VORA Sentinel implements the Damerau-Levenshtein distance algorithm, computing the minimum number of single-character insertions, deletions, substitutions, or transpositions between candidate string a and authentic enterprise string b:

Mathematical Definition:
$$d_{a,b}(i,j) = \min \begin{cases} d_{a,b}(i-1,j) + 1 \\ d_{a,b}(i,j-1) + 1 \\ d_{a,b}(i-1,j-1) + 1_{(a_i \neq b_j)} \\ d_{a,b}(i-2,j-2) + 1 \quad \text{if } a_i = b_{j-1} \text{ and } a_{i-1} = b_j \end{cases}$$

If the computed distance is ≤ 2 characters against an authentic Fortune 500 domain, the domain is classified as CRITICAL TYPOSQUATTING with an immediate risk score penalty of +50.

5.2 Shannon Entropy for DGA (Domain Generation Algorithm) Detection

Cyber syndicates utilize automated DGAs producing pseudorandom domain strings to evade static blocklists. VORA computes the Shannon entropy H(X) across the domain name string:

Shannon Entropy Formula:
$$H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$

Where P(xi) represents the probability of occurrence of character xi. Domains exhibiting an entropy H(X) > 3.8 are automatically flagged as machine-generated malware/phishing domains.

5.3 RFC 3490 Punycode & IDN Homograph Defense

Adversaries exploit internationalized domain names (IDN) by substituting Latin characters with visually indistinguishable Cyrillic or Greek glyphs (e.g. Latin 'o' U+006F substituted with Cyrillic 'о' U+043E). The engine inspects for xn-- Punycode prefixes and non-ASCII character codepoints, instantly classifying them as HIGH-SEVERITY HOMOGRAPH ATTACKS.

5.4 Advance-Fee Extortion NLP Regex Tokenizer

Using natural language entity extraction, the engine scans offer documents for advance-fee extortion patterns:

  • Refundable security deposit, caution deposit, or equipment fee demands.
  • Mandated payment transfer via personal UPI addresses, PhonePe, Paytm, or cryptocurrency.
  • Corporate correspondence sent from free webmail providers (@gmail.com, @yahoo.com).
  • Informal interview routing via unencrypted messaging apps (Telegram bots, WhatsApp groups).
